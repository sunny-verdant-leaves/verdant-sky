# 碧空物语 — 变更日志

# v2.1.4 - 2026-11-05

## 更新内容

_面向玩家：_
- 新增：产能花**饮雪莲**及其浮空变体**浮空饮雪莲**。它们会消耗雪、雪块和雪球来产出魔力。
- 新增：腐朽百子莲盆栽 和 饮雪莲盆栽。
- 新增：内置资源包，使模组中的雪砖材质匹配高版本原版的对应方块。
- 调整：模组雪砖现在使用锹而非镐作为合适挖掘工具，以匹配高版本原版的设定。 
- 调整：模组雪砖不再能通过切石机由雪块合成，以匹配高版本原版的配方。 
- 调整：初始岛现在在生成失败时会提供一个保底的石头平台，防止玩家在开局时直接掉入虚空。
- 移除：特定环境下在初始岛生成的地物。它们是非必要的，且从一开始就未能正常运作。
- 修复：森林初始岛 ID 拼写错误导致在 无中生有空岛 世界预设中生成失败的问题。
- 修复：部分配置项允许设置的最小值与其实际设定的语义不匹配的问题：
  - `decayAgapanthusRadius` 现在要求最小值为 1（以前可以设置为 0）。
  - 将 `decayAgapanthusMaxConversionsPerTick` 设置为 0 现在表示不会进行任何转换（以前至少会转换 1 个）。
  - 将 `decayAgapanthusManaCost` 设置为 0 或负数现在表示不消耗魔力（以前至少会消耗 1 点魔力）。
  - 将 `decayAgapanthusWitherDuration` 设置为 0 现在表示不施加凋零效果（以前至少会施加 1 tick）。
- 修复：腐朽百子莲在魔力不足以支付全部转换时仍会强制转换多个方块，导致魔力透支的问题。
- 修复：浮空花物品在 Fabric 平台上渲染失败的问题。

_面向开发者：_
- 新增：`PlatformBlocks` 类，用于通过跨平台工厂方法注册 `SpecialFlower`。
- 新增：`utils/flower_gen.py`，用于批量生成 `SpecialFlower` 的资源与数据。

**详情**：[v2.1.3...v2.1.4](https://github.com/sunny-verdant-leaves/verdant-sky/compare/v2.1.3...v2.1.4)

# v2.1.0 - 2026-10-12

## 更新内容

- 新增：腐化 配方现在支持位置谓词，可在花朵所在位置检查条件。
- 新增：**JEI** 支持查看“腐化”配方。
- 新增：**EMI** 支持查看“腐化”配方。
- 新增：腐朽百子莲的 **帕秋莉手册** 页面。
- 新增：将白雏菊产物转化为白雏菊原料或其他方块的“腐化”配方。
- 新增：与下界乐事（Nether's Delight）的联动配方。
- 调整：腐朽百子莲的行为：
  - 腐朽百子莲现在只会在成功腐化方块时对周围生物施加凋零效果。这意味着它不再是凋灵玫瑰的廉价上位替代品。
  - 腐朽百子莲现在仅在配置的凋零持续时间为正数时施加凋零效果。
- 调整：减少了腐朽百子莲施加的凋零效果持续时长。
- 调整：降低了腐朽百子莲的最大魔力缓存。
- 调整：降低了每次腐化方块消耗的魔力。
- 移除：将泥土腐化为缠根泥土的配方。

**详情**：[v2.0.11...v2.1.0](https://github.com/sunny-verdant-leaves/verdant-sky/compare/v2.0.11...v2.1.0)
